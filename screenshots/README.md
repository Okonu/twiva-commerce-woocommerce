# Screenshots Directory

This directory should contain screenshots of the plugin interface for documentation purposes.

## Recommended Screenshots

### 1. Overview Tab (overview.png)
- Dashboard showing commission statistics
- Total products and commission values
- Clean, professional interface

### 2. Products Tab (products.png)
- Product listing with categories and commission rates
- Commission amounts in KSH
- "View Product" action buttons
- Warning indicators for uncategorized products

### 3. Categories Tab (categories.png)
- Category listing with commission rates
- Product counts and total values per category
- "View Category" action buttons
- Summary statistics

### 4. Commission Setup Tab (commissions.png)
- Detailed commission rate breakdown
- Category-based rate structure
- Warning messages for uncategorized products

### 5. WordPress Menu (menu.png)
- WooCommerce → Commission Manager menu location
- Plugin activation in WordPress admin

## Screenshot Guidelines

- Use a standard WordPress admin theme (default)
- Capture at 1920x1080 resolution
- Show actual data, not lorem ipsum
- Include both desktop and mobile views if relevant
- Highlight key features and functionality

## File Naming Convention
- Use lowercase
- Use descriptive names
- Use .png format for best quality
- Keep file sizes reasonable (< 500KB each)

To add screenshots:
1. Take screenshots of the working plugin
2. Save as PNG files in this directory
3. Update documentation references
4. Include in distribution package
